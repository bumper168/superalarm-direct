# 超级闹钟（直推版）

一个 Windows 桌面闹钟程序：到点自动弹窗提醒，同时推送到你的微信。**单文件免安装，双击即用**，支持 Windows 10 / 11 64 位。

## 下载

右侧 **Releases** 中下载最新版 `SuperAlarmDirect.exe`（约 155MB，绿色单文件，无需安装 .NET）。

## 快速开始（1 分钟）

1. 双击打开 `SuperAlarmDirect.exe`
2. 点主界面【帮助】，按引导完成微信推送配置：
   - 微信扫码打开 https://sct.ftqq.com ，免费获取 SendKey（SCT 开头）
      - 点【推送设置】→ 填入 SendKey → 勾选“启用推送”
         - 点【发送测试推送】→ 微信收到测试消息即成功
         3. 【新建】闹钟 → 到点自动弹窗 + 微信推送

         ## 功能

         - 8 种提醒类型：一次性 / 每天 / 每周 / 每月 / 农历每年（生日）/ 公历每年（纪念日）/ 开机时 / 关机时
         - 托盘常驻：关窗口不退出，闹钟照常工作
         - 开机自启：点主界面【开机自启】按钮
         - 每台电脑数据独立，互不影响
         - 无广告，绿色单文件

         ## 说明

         - 本程序需要**电脑常开**才能推送闹钟（关闭窗口 = 隐藏到托盘，请勿点托盘“退出”）。
         - 如果要想**关机后也能推送闹钟**，请联系微信 / QQ（同号）： 629714，每个账号 5 元（永久）。
